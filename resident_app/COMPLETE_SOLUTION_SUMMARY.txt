                    COMPLETE SOLUTION SUMMARY
================================================================================

YOUR PROBLEM:
- Error loading bookings [cloud_firestore/permission-denied]
- Error loading announcements
- Full app not working properly

ROOT CAUSE:
- Firestore security rules are blocking all read access
- Flow functions cannot read data from Firestore
- All screens show permission-denied errors

================================================================================
                         THE SOLUTION (5 MINUTES)
================================================================================

STEP 1: Open Firebase Console
  → https://console.firebase.google.com

STEP 2: Select lyvo-app Project

STEP 3: Go to Firestore Database → Rules

STEP 4: Replace Rules
  DELETE everything and PASTE:

  rules_version = '2';
  service cloud.firestore {
    match /databases/{database}/documents {
      match /users/{userId} {
        allow read: if true;
        allow write: if request.auth != null;
      }
      match /{document=**} {
        allow read, write: if request.auth != null;
      }
    }
  }

STEP 5: Click Publish

STEP 6: Refresh App
