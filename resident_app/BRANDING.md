# Lyvo - Branding Guide

## App Identity

### Name
**Lyvo**

### Slogan
**Your Community, Connected**

---

## Brand Essence

Lyvo is a resident community management app that connects neighbors, simplifies living, and enhances community engagement.

### Core Values
- **Connected**: Bringing residents together
- **Simple**: Easy-to-use interface
- **Comprehensive**: All-in-one community solution
- **Trustworthy**: Secure and reliable

---

## Visual Identity

### Primary Color
- **Blue**: `#2563EB` (RGB: 37, 99, 235)
- Represents trust, reliability, and community

### Secondary Colors
- **Dark Blue**: `#1E40AF` (for gradients)
- **Light Gray**: `#F7F7F7` (backgrounds)
- **White**: `#FFFFFF` (cards, active states)

### Typography
- **Font Family**: Inter
- **Weights**: 400 (Regular), 500 (Medium), 600 (Semibold), 700 (Bold)

---

## App Features

### Core Modules
1. **Dashboard** - Quick access to everything
2. **Visitor Management** - Manage guests and deliveries
3. **Billing** - View and pay maintenance bills
4. **Events** - Community events, notices, and polls
5. **Profile** - Personal settings and preferences

### Additional Features
- Community Wall - Social feed for residents
- Marketplace - Buy/sell within community
- Amenities Booking - Reserve facilities
- Complaints - Report and track issues
- Messages - Chat with neighbors and management

---

## User Experience Principles

### Design Philosophy
1. **Clean & Modern** - Minimalist interface
2. **Intuitive** - Easy navigation
3. **Consistent** - Uniform design patterns
4. **Responsive** - Smooth animations
5. **Accessible** - Clear hierarchy and contrast

### Navigation
- Bottom navigation for main sections
- Smooth tab transitions
- Clear back navigation
- Consistent spacing (16px standard)
