# Resident App Dashboard

## Overview
Pixel-perfect Flutter recreation of the Resident App Dashboard screen matching the reference design.

## Features Implemented
✅ Blue gradient header with greeting and apartment info
✅ Apartment image banner with rounded corners
✅ Three summary cards (Pending Bill, Visitor Today, Open Complaint)
✅ Quick Access grid with 8 icon buttons
✅ Recent Activity section with status badges
✅ Emergency SOS button with shadow
✅ Bottom navigation bar with 5 tabs
✅ Exact color scheme matching (#2563EB primary blue)
✅ Proper spacing and shadows
✅ Responsive layout for mobile screens

## Files Created
- `lib/dashboard_screen.dart` - Main dashboard UI
- `lib/main.dart` - Updated app entry point

## How to Run
```bash
cd resident_app
flutter run
```

1. **Header** - Gradient blue header with time, greeting, and apartment info
2. **Image Banner** - Apartment building photo with rounded corners
