# Billing Fetch Debug Guide

## Issue

Billing data not fetching properly from Firestore.

## Debug Steps

### Step 1: Run Debug Script

Add this to your `main.dart` temporarily:

```dart
import 'lib/test_billing_debug.dart';

// In your main() or after Firebase initialization
await testBillingFetch();
```

Or create a button in the app to run it:

```dart
ElevatedButton(
  onPressed: () async {
    await testBillingFetch();
  },
  child: Text('Debug Billing'),
)
```

### Step 2: Check Console Output

Look for these key messages:

#### Success Pattern:
```
🔍 BILLING DATA FETCH DEBUG
📱 CURRENT USER:
   UID: <userId>
✅ User document found
   FlatId: 1202
📋 QUERYING BILLS COLLECTION...
   Query: WHERE flatId == "1202"
✅ Query completed
   Bills found: 1
📊 BILLS DETAILS:
   Bill ID: <billId>
   Amount: 4500
   Status: pending
   ChargeBreakdown:
      Electricity: 1500
      Maintenance: 1000
      ...
```

#### Problem Patterns:

**Pattern 1: No FlatId**
```
❌ No flatId assigned to user
```
**Fix**: Add `flatId` field to user document in Firestore

**Pattern 2: No Bills Found**
```
⚠️  NO BILLS FOUND
   Possible reasons:
   1. No bills exist for flatId: 1202
```
**Fix**: Create bill document in Firestore

**Pattern 3: FlatId Mismatch**
```
✅ Query completed
   Bills found: 0
   Debug: Total bills for flat 1202: 0
```
**Fix**: Check if bill's `flatId` matches user's `flatId` exactly

## Common Issues & Fixes

### Issue 1: User has no flatId

**Symptoms**:
- Console shows: "No flatId assigned to user"
- Screen shows: "No Pending Bills"

**Fix**:
1. Open Firebase Console
2. Go to Firestore Database
3. Find user document
4. Add field: `flatId: "1202"`
5. Restart app

### Issue 2: Bill flatId doesn't match

**Symptoms**:
- User has flatId
- Bills exist in Firestore
- But no bills showing

**Fix**:
1. Check user's flatId: `"1202"`
2. Check bill's flatId: `"1202"`
3. Ensure they match EXACTLY (case-sensitive)
4. Update bill if needed

### Issue 3: Bill status not "pending"

**Symptoms**:
- Bills exist
- But current bill not showing

**Fix**:
1. Check bill's `status` field
2. Should be: `"pending"` (lowercase)
3. Not: `"Pending"` or `"PENDING"`
4. Update if needed

### Issue 4: No chargeBreakdown field

**Symptoms**:
- Bill shows
- But breakdown is empty or shows "No breakdown available"

**Fix**:
1. Add `chargeBreakdown` field to bill document:
```json
{
  "chargeBreakdown": {
    "Electricity": 1500,
    "Maintenance": 1000,
    "Water": 1000,
    "Service": 500,
    "Parking": 250,
    "Security": 250
  }
}
```

## Quick Fixes

### Fix 1: Add FlatId to User
```dart
// Run in Firebase Console or app
await FirebaseFirestore.instance
    .collection('users')
    .doc(userId)
    .update({'flatId': '1202'});
```

### Fix 2: Update Bill FlatId
```dart
// Run in Firebase Console or app
await FirebaseFirestore.instance
    .collection('bills')
    .doc(billId)
    .update({'flatId': '1202'});
```

### Fix 3: Add ChargeBreakdown
```dart
// Run in Firebase Console or app
await FirebaseFirestore.instance
    .collection('bills')
    .doc(billId)
    .update({
      'chargeBreakdown': {
        'Electricity': 1500,
        'Maintenance': 1000,
        'Water': 1000,
        'Service': 500,
        'Parking': 250,
        'Security': 250,
      }
    });
```
