## 🎯 Create Upload Preset (5 minutes)

### Step 1: Go to Cloudinary
https://cloudinary.com/console

### Step 2: Click Settings (gear icon)

### Step 3: Click Upload Tab

### Step 4: Scroll to "Upload presets"

### Step 5: Click "Add upload preset"

### Step 6: Fill Form
| Field | Value |
|-------|-------|
| Preset name | `apartment_images_preset` |
| Signing Mode | **Unsigned** |

### Step 7: Click Save

---

## ✅ Done!

The preset is created. Now test the feature:

1. Run the app
2. Go to Apartment Images
3. Click "Add Image"
4. Select image
5. Set date and time
6. Click "Upload Image"
7. Verify success
