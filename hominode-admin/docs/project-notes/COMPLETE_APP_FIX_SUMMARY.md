## 🏗️ Firestore Structure

### Collections Created
1. **admins** - Admin profiles and building lists
2. **buildings** - Building information and occupancy
3. **flats** - Flat information and resident assignments
4. **users** - Resident information and assignments

### Data Relationships
```
admins/{uid}
  ├── buildingIds: [building1, building2, ...]
  └── buildings: [{buildingId, buildingName, ...}, ...]

buildings/{buildingId}
  ├── adminId: uid
  └── buildingId: buildingId

flats/{flatDocId}
  ├── buildingId: buildingId
  ├── adminId: uid
  └── residentUserId: uid (if assigned)

users/{uid}
  ├── adminId: uid
  ├── buildingId: buildingId
  └── flatId: flatDocId (if assigned)
```
